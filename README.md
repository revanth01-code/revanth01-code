# I'm Revanth.

I got into AI/ML trying to answer one question:

> *What does it actually take to make an LLM do something useful in the real world?*

Not useful in a demo. Useful when things break, tokens expire, agents hallucinate, and queues back up. That gap between "it works in a notebook" and "it works in production" — that's where I've spent most of my time.

---

## Work

**[Agentflow-AI](https://agentflow-ai-omega.vercel.app/) &nbsp;·&nbsp; [GitHub](https://github.com/revanth01-code/agentflow_ai)**

No-code workflow automation — describe what you want in plain English, get a running workflow graph. Five LangGraph agents handle planning, execution, validation, recovery, and monitoring. Real-time events over Socket.IO. BullMQ + Redis for the job queue. Gmail, Slack, Discord, and Google Sheets over OAuth 2.0.

The interesting engineering problem was reliability — making sure no token expiry or missing credential ever failed silently. Every failure has a known path.

**[FinPilot](https://v1-eight-ivory.vercel.app/) &nbsp;·&nbsp; [GitHub](https://github.com/revanth01-code/v1) &nbsp;·&nbsp; PEC Hacks 4.0 Finalist**

Financial planning platform built at a national hackathon — 36 hours, 18K+ registrations. Goal feasibility engine, inflation-adjusted SIP calculator, conflict detection across competing goals, async LangChain + Groq AI coach with fallback handling. Four people, one weekend, made the finals.

**RAG Pipeline with Hybrid Search &nbsp;·&nbsp; In Progress**

Document intelligence API — drop in any corpus, get grounded answers with source citations. Hybrid retrieval: dense vector search + BM25 sparse search fused via Reciprocal Rank Fusion. Production FastAPI service, endpoint versioning, async throughout.
